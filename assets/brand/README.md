# PLParadis brand assets

The mark combines three elements:

- Green Mountain terrain for Vermont and rural roots
- An adjustable wrench for mechanical and HVAC engineering
- An amber streamline for airflow, heat transfer, and energy

## Palette

- Dark evergreen: `#183A32`
- Warm amber: `#FFAF31`

## Files

- `plparadis-logo.svg`: scalable transparent master
- `plparadis-logo.png`: transparent high-resolution raster version
- `plparadis-avatar-512.png`: square GitHub and social avatar
- `favicon-32.png`: 32 px browser icon
- `favicon-16.png`: 16 px browser icon
- `favicon.ico`: multi-resolution browser favicon

The PNG artwork is suitable for immediate digital use. A manually redrawn SVG should be produced before large-format print, fabrication, or trademark filing.
